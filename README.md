
# SHA Hash Generator

A simple, responsive web application that allows users to generate SHA-1 or SHA-256 hashes for any input text using the browser's built-in Web Crypto API.

## 🚀 Features

- Supports **SHA-1** and **SHA-256** hash algorithms
- Fully client-side – no data is sent to a server
- Clean, responsive UI built with HTML, CSS, and JavaScript
- Instant hash generation on button click

## 🖥️ Live Demo

You can open the `index.html` file in any modern browser to use the tool.

## 📦 Usage

1. Clone or download the repository.
2. Open the `index.html` file in your web browser.
3. Enter the text you want to hash.
4. Choose the desired hash algorithm (`SHA-1` or `SHA-256`).
5. Click **"Generate Hash"** to see the output.
